# Security Policy

## Reporting

If you discover a security issue in this repository, please report it responsibly
to the repository maintainers. Do not open public issues with exploit details.

## Scope

This project is an early scaffold. Treat all deployments as **non-production**
until you have completed your own security review, hardening, and compliance work.

## Principles encoded in the architecture

- Zero Trust: verify identity and permissions
- Least privilege for agents and tools
- Human approval for device and external connections
- Audit and evidence logging for significant actions
- No automatic connection or control of physical devices

## Your responsibility

You are responsible for securing any deployment, secrets, data, and integrations
you operate. See `USER_AGREEMENT.md`.
