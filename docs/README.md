# KCN Studio Home (public static)

## Enable GitHub Pages (gives you a live URL)

1. Open https://github.com/Evank253/KCN_SINGULARITY_MASTER/settings/pages
2. **Source:** Deploy from a branch
3. **Branch:** `main`
4. **Folder:** `/docs`
5. Save

Your site will be:

**https://evank253.github.io/KCN_SINGULARITY_MASTER/**

That page is **Studio Home** (choose Build, Auto, Marine, Aero, Robotics, Software).

## Files

- `index.html` — Studio Home
- `workspace.html` — workspace shell per studio
